# PantallaAcceso

Pantalla de inicio de sesión (CU-01) con campos grandes (`size="lg"`) para uso táctil, aviso de error en línea y un único botón principal.

## Decisiones de diseño

- Una sola columna centrada; el logo de Progresol y el nombre del sistema en la parte superior.
- Etiquetas visibles, `autocomplete` correcto y botón para mostrar la contraseña.
- El mensaje de error no revela cuál de las dos credenciales falló.

title CU-04: Consultar disponibilidad

actor "Almacenero/Vendedor" as Actor
boundary InterfazConsultas
control InventarioController
participant KardexService
participant InventarioRepository
database BD

Actor -> InterfazConsultas: ingresar búsqueda (SKU o nombre)
InterfazConsultas -> InventarioController: getStockPorUbicacion(termino)
InventarioController -> KardexService: consultarStockPorUbicacion()

KardexService -> InventarioRepository: buscar existencias
InventarioRepository -> BD: select por ubicación
BD --> InventarioRepository: resultados (Lista de Inventario)
InventarioRepository --> KardexService: datos

alt Producto encontrado
    KardexService --> InventarioController: List<Inventario>
    InventarioController --> InterfazConsultas: disponibilidad segmentada
    InterfazConsultas --> Actor: mostrar stock real
else Producto no encontrado / ambiguo
    KardexService --> InventarioController: vacío o sugerencias (Fuzzy)
    InventarioController --> InterfazConsultas: opciones
    InterfazConsultas --> Actor: mostrar alternativas
end

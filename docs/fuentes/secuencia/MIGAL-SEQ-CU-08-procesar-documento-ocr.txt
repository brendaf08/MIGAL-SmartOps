title CU-08: Procesar documento con OCR (ADR-011 y ADR-012)

actor "Vendedor/Almacenero" as Actor
boundary InterfazOCR
control DocumentoOcrController
participant DocumentoOcrService
participant EnvioOcrHttp
participant "Servicio OCR (Python)" as PythonOCR
participant "API Gemini" as Gemini
participant VigilanciaOcr
database BD

Actor -> InterfazOCR: cargar documento y tipoDocumento
InterfazOCR -> DocumentoOcrController: POST /documentos (multipart)
DocumentoOcrController -> DocumentoOcrService: cargar(archivo, tipo)
DocumentoOcrService -> BD: insert documento_digital (pendiente, fecha_encolado)
DocumentoOcrService --> DocumentoOcrController: documento pendiente
DocumentoOcrController --> InterfazOCR: 202 Accepted

note over EnvioOcrHttp: después de confirmar la transacción (AFTER_COMMIT)
EnvioOcrHttp -> DocumentoOcrService: catalogoActivo()
DocumentoOcrService -> BD: select productos activos
EnvioOcrHttp -> PythonOCR: POST /procesar (archivo, catálogo, token por documento, X-Token-Interno)
PythonOCR --> EnvioOcrHttp: 202 Accepted

PythonOCR -> Gemini: transcribir líneas y cantidades
Gemini --> PythonOCR: líneas leídas (JSON)
PythonOCR -> PythonOCR: normalizar jerga y medidas\nasignar SKU con RapidFuzz

alt Documento legible
    PythonOCR -> DocumentoOcrController: PUT /documentos/{id}/resultados (procesado, coincidencias)
    DocumentoOcrController -> DocumentoOcrService: registrarResultados()
    DocumentoOcrService -> BD: insert detalle_extraido y coincidencias\n(asocia la única coincidencia de confianza alta)
else Documento ilegible
    PythonOCR -> DocumentoOcrController: PUT /documentos/{id}/resultados (ilegible)
    DocumentoOcrService -> BD: codigo_error = DOCUMENTO_ILEGIBLE
else Sin respuesta en 60 s
    VigilanciaOcr -> BD: codigo_error = SERVICIO_NO_DISPONIBLE (reprocesable)
end

InterfazOCR -> DocumentoOcrController: GET /documentos/{id} (sondeo)
DocumentoOcrController --> InterfazOCR: líneas, coincidencias y umbrales
Actor -> InterfazOCR: revisar, corregir y confirmar productos
InterfazOCR -> DocumentoOcrController: PUT /documentos/{id}/detalles/{idDetalle}
InterfazOCR -> DocumentoOcrController: POST /documentos/{id}/validacion
DocumentoOcrService -> BD: documento validado
DocumentoOcrController --> InterfazOCR: disponible para cotización o recepción

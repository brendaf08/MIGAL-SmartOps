# PantallaInventarioMovil

Variante de teléfono de la pantalla de disponibilidad. La navegación pasa a un panel deslizable que se abre con el botón de menú; la cabecera de 56 px conserva el nombre del sistema, el cambio de modo y el avatar. La tabla se presenta como fichas: el producto como título, la cantidad libre y el nivel visibles, y las columnas por ubicación omitidas (`phone: false`) para consultarlas en el detalle. La búsqueda y las pestañas ocupan el ancho completo.

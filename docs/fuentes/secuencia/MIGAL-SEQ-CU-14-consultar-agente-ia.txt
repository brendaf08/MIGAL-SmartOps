title CU-14: Consultar agente de IA (ADR-012)

actor Usuario
boundary InterfazAsistente
control AgenteIaController
participant ServicioAgente
participant CatalogoHerramientas
participant "API Gemini" as Gemini
participant "Servicios de dominio" as Servicios
database BD

Usuario -> InterfazAsistente: enviar consulta
InterfazAsistente -> AgenteIaController: POST /agente/mensajes
AgenteIaController -> ServicioAgente: enviar(usuario, mensaje, conversacion)
ServicioAgente -> BD: lectura corta: conversación propia y últimos mensajes
ServicioAgente -> CatalogoHerramientas: herramientas permitidas al rol

note over ServicioAgente, Gemini: sin transacción abierta durante las llamadas al modelo
ServicioAgente -> Gemini: planificar (consulta, historial, herramientas)
Gemini --> ServicioAgente: llamadas a herramientas (máximo 3)

loop por cada herramienta elegida
    ServicioAgente -> CatalogoHerramientas: ejecutar(rol, herramienta, parámetros)
    CatalogoHerramientas -> Servicios: consulta de solo lectura
    Servicios -> BD: select
    Servicios --> CatalogoHerramientas: datos
    CatalogoHerramientas --> ServicioAgente: resumen y referencias
end

alt Hay datos de alguna herramienta
    ServicioAgente -> Gemini: redactar (JSON con consulta y resultados)
    Gemini --> ServicioAgente: texto e indicador de incertidumbre
else Sin datos
    ServicioAgente -> ServicioAgente: respuesta incierta sin inventar cifras (RF-IA-08)
end

ServicioAgente -> BD: escritura corta: mensaje del usuario y respuesta
ServicioAgente --> AgenteIaController: respuesta, herramientas y referencias
AgenteIaController --> InterfazAsistente: mostrar respuesta

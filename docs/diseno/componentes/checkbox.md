# Checkbox

Casilla de verificación para opciones independientes y selección múltiple en tablas.

## Uso

- `label`, `description`, `checked` / `defaultChecked`, `onChange`, `indeterminate`, `disabled`.

## Reglas

- La etiqueta es parte del área clicable (mínimo 24 px de objetivo, 44 px en tablets mediante el relleno de la fila).
- Para opciones excluyentes usar un selector o botones de opción, no varias casillas.
- Estado `indeterminate` solo para casillas que resumen una selección parcial.

Equivalente en Mantine: `Checkbox`.

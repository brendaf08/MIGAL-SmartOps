# PantallaRecepcionOCRMovil

Variante de teléfono de la recepción con OCR. El `Stepper` pasa a vertical, las acciones de la cabecera se apilan a ancho completo y cada línea extraída es una ficha cuyos controles (producto, coincidencia y cantidad recibida) ocupan todo el ancho para operarse con el pulgar.

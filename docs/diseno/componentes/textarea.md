# Textarea

Campo de texto de varias líneas para motivos, observaciones y condiciones comerciales.

## Uso

- Mismos props de campo que `TextInput`; `rows` (3 por omisión).
- Motivo de mermas, ajustes y cancelaciones: `required` con ayuda que indique la finalidad (RF-KAR-14, cancelación de venta con motivo).

## Reglas

- Mostrar el límite de caracteres en la ayuda cuando exista.
- Altura redimensionable solo en vertical.

Equivalente en Mantine: `Textarea` con `autosize`.
